Cinq directions.
Un même système.

Cinq mini-sites navigables pour le futur site du studio. La direction artistique change ; le contenu, la structure et les prix sont identiques. Aucun nom de marque n’est arrêté, aucune référence client n’est inventée.

01

Le même contenu

Chaque prototype reprend mot pour mot la promesse, les trois portes, la méthode, les offres et les six questions de contact. Seuls le traitement visuel, la typographie et le mouvement changent.

02

Une seule base

Un modèle de contenu, un layout, des composants partagés et cinq thèmes. Pas cinq sites à maintenir : une route dynamique produit les cinq pages.

03

Aucune décision prise

Pas de nom, pas de logo, pas d’identité définitive. Les travaux montrés sont internes ou des formats de mission, jamais des références clients.

Différences objectives

Ce qui change réellement.

Pas de note, pas de classement. Le contenu est stable ; ce tableau décrit le mécanisme visuel et le risque assumé de chaque direction.

Direction Thèse Moteur Risque
01 BOLD CREATIVE Le système est un geste. DOM + CSS La lisibilité peut payer le spectacle.
02 ARCHITECTURAL PRECISION La précision se voit. SVG + CSS Trop de silence peut sembler distant.
03 DIGITAL FRONTIER Le code comme paysage. Canvas 2D Le canvas coûte du CPU : il doit savoir s’arrêter.
04 EDITORIAL CULTURE Une revue, pas un site. Typographie + CSS La densité peut ralentir la lecture mobile.
05 FUTURE SYSTEMS Le système en salle de contrôle. SVG + CSS Le décor peut écraser le message.

Choisir

    Laquelle enverriez-vous à un directeur technique que vous ne connaissez pas ?

    Laquelle pourriez-vous maintenir seul pendant trois ans ?

Le choix se joue sur ce qui reste quand l’effet est retiré. Les cinq directions ont été construites pour que ce reste soit le même contenu, pas le même spectacle.
